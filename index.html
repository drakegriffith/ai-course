How to Use AI Like a Software Engineer

with Claude Code & Codex

This course teaches ordinary people, no programming background needed, to set up and run AI the way software engineers do: from the terminal, with saved skills, a personal knowledge vault, and small systems that check their own work. It is streamed live on Twitch every Tuesday and Thursday, and each stream is cut into a YouTube episode afterward. By the end you will have built a personal AI setup that runs daily jobs for you and measurably improves itself. Every episode produces one thing you keep.

All course files live in the GitHub repository. Green numbers are video lengths. Blue links open the lesson or episode.

Prerequisite: Course 0, Terminal Fluent

Four short written lessons that take you from never having opened a terminal to comfortably driving Claude Code and Codex from one. Course 1 assumes all of it.

read Lesson 1: The Terminal Itself

The eight commands that make you dangerous, how paths work, and the two habits (Tab completion, Ctrl+C) that separate the fluent from the frustrated.

read Lesson 2: The Claude Code Cockpit

Install, log in, and read the two gauges everyone confuses: usage (the money dial) and context (the attention dial). Compact vs clear, calling skills, plugins, and the CLAUDE.md memory file.

Video A (the Claude cockpit): coming soon.

read Lesson 3: The Codex Cockpit

Same gauges, different dashboard. The heart of the lesson is a translation table mapping every Claude concept to its Codex twin, so you stop caring which tool you sat down at.

Video B (the Codex cockpit): coming soon.

read Lesson 4: GitHub, the Words and the One Move

The eight words (repo, commit, clone, push, pull, README, fork, issue) and the one move: cloning this course onto your own machine so you can follow along.

Syllabus

Thirty core episodes in four bands, then solo project briefs. Episodes stream live Tuesdays and Thursdays; the YouTube link and running time land here after each cut.

Band 1, Beginner: Own Your Setup (episodes 1-8)

upcoming 1. Log On and Build Your First Skill

Log in to Claude Code and Codex and build a skill you can call from any terminal. Fully copy-along; the explanations catch up in episode 2.

upcoming 2. Fluent in the Terminal: the Claude and Codex Cockpits

Both cockpits mastered live: gauges, compact, skills, plugins, and the Claude-to-Codex translation table. First diagram drawn.

upcoming 3. Build the Brain Vault

A folder of linked notes your AI can read. Opens with the four kinds of memory: notes, instructions, the context window, and retrieval.

upcoming 4. Clean the Vault Before It Buries You

A findability test, dead links purged, and git in fifteen minutes: init, commit, restore, so deleting becomes safe.

upcoming 5. Finalize the Harness

A lean entry file built from earned principles. CLAUDE.md and AGENTS.md, same idea on both surfaces: a router, not an encyclopedia.

upcoming 6. Skills Done Properly

Two or three real skills built with the skill-creator method, including one distilled from a software engineering book principle.

upcoming 7. Keys and Safety in Plain English

Where keys live so they never end up public, a rotation drill with a dummy key, and the rule that outside content is data, never instructions.

upcoming 8. CAPSTONE: The Starter Kit From Zero

The whole setup rebuilt live on a fresh account, from the runbook you have been keeping since episode 1.

Band 2, Intermediate: Daily Workflows (episodes 9-16)

upcoming 9. Draw It: Excalidraw and Excel

The full diagram method, plus one Excel chart from your own data. A diagram you drew beats a paragraph you read.

upcoming 10. Make the Vault Talk Back: Semantic Search

Ask your vault questions in plain English. The index / retrieve / generate split, a live bad retrieval, and the fix.

upcoming 11. The Everyday Loop

A summarize-draft-review workflow, with the standing rule: review everything the machine sends out under your name.

upcoming 12. Hooks: Rules That Fire Themselves

One working hook. Rules you must remember will be forgotten; rules that fire themselves won't.

upcoming 13. Your First Subagent

A research task delegated to a second agent and merged back. Delegate for attention, not for speed.

upcoming 14. When "Done" Is a Lie: Your First Golden Set

A frozen set of known-good examples, and a verify step wired after every AI "done". A checker is never the worker.

upcoming 15. APIs 101

A real token, one live call, and JSON as the shape services speak. The run log starts here: every call leaves a record.

upcoming 16. CAPSTONE: The Morning Assistant

A daily personal-brief workflow, end to end, writing its own run log, rebuilt from the runbook.

Band 3, Intermediate+: Connect Everything (episodes 17-24)

upcoming 17. MCP: One Standard, Many Tools

Your first MCP server, and the warning that ships with it: content a server fetches is data, never instructions.

upcoming 18. Chatbot on Your Website, Part 1

A bot wired to your site, answering from your own content. This is RAG, named plainly: ingest, chunk, index, retrieve.

upcoming 19. Chatbot on Your Website, Part 2

Guardrails and a public deploy your friends can visit. When the bot is unsure, it stops.

upcoming 20. Automations on a Schedule

One automation delivering daily, honest about the laptop-not-server reality. Schedules beat willpower.

upcoming 21. Models and Money

A routing rule, a budget cap, and reading your own bill. Route the cheap model first; pay for judgment, not typing.

upcoming 22. Context Hygiene

Context is a budget, not a bottomless well: a token habit and a measured before/after.

upcoming 23. Many Agents, One Job

A small fan-out: split, work, merge, verify, shipped as a reusable template, with its costs stated.

upcoming 24. CAPSTONE: The Connected System

Vault, skills, MCP, and automations wired end to end from the runbook. A system is done when someone else can run it.

Band 4, Advanced: The Self-Improving System (episodes 25-30)

upcoming 25. The Optimization Loop

A loop that is measurable, incremental, and fed back, scored against the golden set from episode 14.

upcoming 26. Improve Itself Overnight

Freeze the test, mutate the system, keep only what scores. An overnight loop with a cheap model as the judge.

upcoming 27. Watch the Watcher

The run log grown into basic telemetry: what ran, what failed, what it cost. The ledger is enough at this scale.

upcoming 28. Delete by Measurement

One real ablation: a rule removed because the numbers said so. Safety rules are not up for ablation.

upcoming 29. The Reset Ritual

When a new model generation lands, every rule re-earns its place: a written keep/wipe pass over your own setup.

upcoming 30. FINAL CAPSTONE: Rebuild the Spine

The core spine rebuilt live from the runbook in one stream. The proof is a rebuild from zero.

After episode 30

Solo project briefs (episodes 31-45, flexible count): you build, the stream reviews. Briefs are posted in the repository as they open.
