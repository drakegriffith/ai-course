# Your Desk

This folder is your desk. You work here while you watch. Nothing you do
inside this folder can break the course for anyone, including you.

## How you got here, and how to get back

You cloned the course with `git clone`, then walked into this exact folder:

```
cd ~/ai-course/00-terminal-fluent/follow-along
```

Bookmark that command. Every time you sit back down to this course, that is
the line you type first. If you are ever lost, `pwd` tells you where you are
standing, and the line above gets you home.

## Your files stay on your machine

This repo is a library book, not a shared notebook. You can read it and pull
new pages, but you cannot write in the copy on the shelf. Anything you make
in this folder, any file, any note, any half-finished script, lives only on
your computer. There is no `git push` for you to run here, and that is fine.
Nobody expects one.

## Pulling updates will not eat your files

When a new lesson goes up, you run `git pull` from inside `ai-course` and the
new files arrive. `git pull` only adds and updates files the instructor
tracks. It does not touch files you created yourself, as long as you did not
give one of your files the exact same name as a file the instructor added.
When in doubt, name your files after yourself, not after the lesson.

## What is in here

- `01-terminal/` - scratch space for Lesson 1. Practice `mkdir`, `cat`, and
  `echo` here without worrying about tidiness.
- `02-claude/` - where you run Claude Code from, with a starter `CLAUDE.md`
  for you to edit.
- `03-codex/` - where you run Codex from, with a starter `AGENTS.md` for you
  to edit.
- `my-runbook.md` - your running "how I set this up" notes. Course 1 grades
  your capstone against a file like this one, so start the habit now.
