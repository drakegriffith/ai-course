# 01-terminal

Scratch space for Lesson 1. Nothing in here is graded or checked.

Walk into this folder with `cd` and try the eight commands from the lesson:
make a folder with `mkdir`, write a file with `echo "text" > name.md`, read
it back with `cat`. Break things on purpose. This is the one folder in the
whole course built for exactly that.

If you lose track of where you are, run `pwd`. If the screen gets messy, run
`clear`. Nothing here can leave this folder and nothing here can hurt the
course.
