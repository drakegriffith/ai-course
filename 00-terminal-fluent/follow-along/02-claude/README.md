# 02-claude

Start Claude Code from inside this folder:

```
cd ~/ai-course/00-terminal-fluent/follow-along/02-claude
claude
```

`CLAUDE.md` in this folder is a memory file. Claude Code reads it every time
you start a session here and treats whatever is written inside as standing
instruction. A starter copy is already sitting in this folder. Open it, read
it, and add a line or two in your own words.

Anything you build or break in here stays on your machine. Practice freely.
