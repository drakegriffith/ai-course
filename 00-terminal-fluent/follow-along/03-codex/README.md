# 03-codex

Start Codex from inside this folder:

```
cd ~/ai-course/00-terminal-fluent/follow-along/03-codex
codex
```

`AGENTS.md` in this folder is Codex's memory file, the same idea as
Claude's `CLAUDE.md`, different tool, different name. Codex reads it every
time you start a session here. A starter copy is already sitting in this
folder. Open it, read it, and add a line or two in your own words.

Anything you build or break in here stays on your machine. Practice freely.
